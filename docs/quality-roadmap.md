# 质量功能实现与验收

本轮范围：引用还原、上下文情境识别、人物结论审阅、留出会话测评、相关记忆检索、盲评与多轮对比、生成断点续跑，以及 CI。

保持 Python 3.10+ 标准库运行依赖，沿用现有界面和版本快照。网络分析由用户显式选择；API Key 不写入包、日志或检查点。

## 行为契约

- 引用：解析结构化 message ID/reply-to，只有唯一且先于回复的真实输入可配对；未解析引用可人工关联，保存前验证说话人和编号，生成时复用关联。
- 情境：结合最近对话区分叙事、玩笑、质疑、求安慰；模糊或多重匹配保留不确定。可选模型分析必须返回实际上下文证据，不把自报分数当准确率。
- 审阅：特点卡包含原话、待核对的反例、适用范围。保留、改写和否定存本地，重新生成与增量更新继续应用；人工内容明确标记来源。
- 留出：按完整会话拆分，只从训练会话生成统计、人设、记忆、示范及参考资料。测试输入、答案留在本地，不进 ZIP 或生成提示词。记录测试集身份并在更新后标记失效。
- 检索：固定人设保留，按输入及最近上下文选择有限条记忆和真实示范；显示本次引用来源。无相关证据时不强行补记忆。
- A/B：支持用例级随机左右排序、选择后揭晓、固定输入的多轮运行，追问使用各侧自己的回复历史。
- 续跑：检查点与输入/模型/配方绑定，成功批次复用，失败批次可重跑，停止在当前调用后生效；显示批次进度与接口返回用量。
- CI：Windows/Linux 单测及独立进程冒烟，Chromium 浏览器验收；使用合成记录及本地模型替身。

## 验证

各模块增加边界测试及本地 HTTP 集成测试。最终运行完整单测、冒烟、浏览器验收、JS 语法检查和 git diff --check。真实模型语感仍由用户对照判断；CI 不依赖外部模型和 Key。

## 实现与复核

- 引用还原：`quote_links.py`、消息元数据与解析器；覆盖错误相邻输入、重复 ID、向前引用、同说话人引用、完整连发、已有引用不被人工关联破坏。
- 结论审阅：`claims.py`；验证保留/改写的范围进入生成及增量导出的人物特点，否定决定跨重生成保留。候选反例仍需人工核对。
- 情境/检索：`semantic.py`、`retrieval.py`；验证上下文证据、短句追问、检索预算、历史状态与原话编号。
- 留出：`holdout.py`；验证完整会话拆分，训练基线/ZIP/模型提示词不包含独特测试答案；旧反馈和实时补标隔离，内容改变后失效。
- 盲评：`ab.py`；验证随机显示位置与实际配置/Key/投票对应，多轮历史互相隔离，揭晓后按实际模型统计。
- 续跑：`checkpoint.py`；验证成功批次复用、失败重试、停止后恢复、取消接口状态、用量进度以及 Key 不进入检查点。
- 浏览器：新增审阅、引用关联、留出模型测评和多轮盲评操作；仍覆盖旧包、原有功能、回滚、移动端 390/320 像素。使用合成记录及本地模型替身。

本地 Windows 上的单测、冒烟和 Edge 浏览器检查用于交付验收。GitHub Actions 配置包含 Linux/Windows 与 Chromium；远端运行结果另行确认。没有以真实模型语感作自动通过结论。
