# 离线生成前后对照

本页使用同一份 `samples/demo-chat.json`，对照修改前后为潘小雨生成的技能。新版在 Output 中，旧版在 Previous Output 中。

这是离线生成产物的对照，没有调用外部 LLM，也没有完成实际试聊评测。测试通过和原话命中只能验证生成链路与出处，不能证明试聊已经像本人。

## 建议重点查看

- **感谢后的接法**：对方说「我擦」「谢了 要不是你我又忘了」，TA 回「请我喝水」。关注这类具体回应是否比“幽默、随和”更有用。
- **被翻旧账时的措辞**：对方说「烧烤那次」，TA 回「……那叫改期」。新版保留抓住说法、短句改口的动作，并注明跨会话重复的观察依据。
- **被要求正经时怎样接梗**：对方说「？？」「正经点」，TA 回「很正经 食物链顶端的队名」。检查是否保留完整接话，而不是拆成孤立的口头禅。
- **错误配对是否消失**：旧版将「让阿姨多抖两下」与另一个会话的「晚安」配在一起；新版只从同一会话内的相邻接话提取示范。

## 新版文件

`SKILL.md` 保留人物特点、情境接法和示范；`memory.md` 保留共同经历；`profile.md` 记录统计及观察范围；`quotes.md` 提供原话出处。

单次接法标为“单次观察”，只用于相似语境；话题词不再直接充当口头禅，样本里没出现的表达也不再变成永久禁令。示范中的旧地点和承诺不能当作当前事实复述。

## 已完成的验证

25 项测试通过。新版样例有 2 条跨会话重复的人物特点、6 条情境接法和 8 段接话示范。84 条待核验内容全部命中原文，未找到依据和日期不符均为 0。

继续判断人物还原效果时，应在新的相似场景中试聊，观察是否能自然沿用回应动作，而不是只复述旧台词。
